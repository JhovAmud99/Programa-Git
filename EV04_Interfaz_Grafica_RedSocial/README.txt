NOTA
Este proyecto es una interfaz frontend de demostración. No utiliza servidor, autenticación real ni base de datos. Las publicaciones y 
mensajes creados durante la prueba existen solo mientras la página permanece abierta.

PROYECTO FRONT-END - RED SOCIAL ADSO
====================================

Programa: ADSO - Análisis y Desarrollo de Software

Este proyecto implementa el diseño front-end de una red social mediante HTML5, CSS3 y JavaScript. Retoma la propuesta visual de evidencias anteriores: verde claro #D3EADA, blanco/gris #D9D9D9, rojo #D32F2F para alertas, tipografía Roboto y componentes adaptables a móviles.

PANTALLAS
- index.html: inicio de sesión
- registro.html: registro de usuario
- inicio.html: muro/pantalla principal
- perfil.html: perfil
- mensajes.html: mensajería
- notificaciones.html: notificaciones

RECURSOS
- css/estilos.css
- js/script.js
- img/logo.svg
- img/avatar.svg

INTERACCIONES JS
- Validación básica de login y registro.
- Navegación entre pantallas.
- Recuperación de contraseña en modo demostración.
- Crear publicaciones dinámicamente.
- Me gusta.
- Enviar mensajes.
- Marcar notificaciones como leídas.
- Edición de perfil en modo demostración.

EJECUCIÓN
1. Descomprimir.
2. Abrir index.html en Chrome, Edge o Firefox.
3. El sistema es un front-end académico: no incluye backend, base de datos ni autenticación real.
